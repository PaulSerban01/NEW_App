Component

Select

Single-select dropdown built on el-select. Tailwind utility markup, Lucide chevron-down trigger and check indicator, with every color bound to a design-system token so it follows the active palette and light / dark mode.

Basic example

Outline trigger, selected value mirrored into el-selectedcontent. Highlighted option uses the accent token; the checkmark marks the current selection.
