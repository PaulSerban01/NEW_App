Component

App header

The fixed top region of every mobile screen. A single wrapper holds the header bar (navigation control, title, avatar) and an optional slot for per-page detail rows, closed by exactly one bottom border. Hidden on desktop, where the persistent sidebar takes over.

Anatomy

Three parts, one border. The wrapper is the fixed, bordered container. The header bar is always present. The extras slot is empty on most screens and holds extra rows on the ones that need them — all above the single divider.

  • Wrapper — position: fixed, --bg-surface background, one border-bottom.
  • Header bar — leading control (Home or Back), centered title, trailing avatar.
  • Extras slot (#header-extras) — per-page detail rows; sits below the bar, above the border.

Default — header bar only

The baseline state used by most screens: leading Home control, centered title, profile avatar. The single border closes the region.

With detail rows

A page can mount extra rows into the slot — a breadcrumb, a filter bar, a summary line. However many rows are added, there is still just one border at the bottom of the region.

Behavior

  • Fixed, never overlapping. The wrapper is out of flow; the app shell reserves space with padding-top: var(--app-header-h).
  • Self-measuring. A ResizeObserver keeps --app-header-h equal to the header's real height, so adding or removing rows never hides page content.
  • One border, always. The divider lives on the wrapper — extra rows are added inside it, so the count never changes.
  • Transient slot. #header-extras is cleared on every navigation; a page re-populates it inside its own render.
  • Notch-safe. padding-top: env(safe-area-inset-top) clears the status bar in installed-PWA mode.
  • Route-aware leading control. Shows Home on top-level screens and Back when a detail or sub-page is open.
  • Mobile only. Hidden at the xl breakpoint — desktop uses the sidebar.

Markup

<!-- Fixed wrapper — owns positioning and the single border -->
<div id="app-header"
     class="header-mobile fixed inset-x-0 top-0 z-30 bg-surface
            border-b border-border-subtle pt-[env(safe-area-inset-top,0px)]">

  <!-- The header bar -->
  <header class="flex items-center gap-2 p-3">
    <a id="home-btn" href="#/" aria-label="Acasă">…</a>
    <button id="back-btn" aria-label="Înapoi" class="hidden">…</button>
    <div id="header-title" class="flex-1 text-center font-semibold">Rurio</div>
    <a id="header-avatar" href="#/profile" aria-label="Profil">…</a>
  </header>

  <!-- Per-page detail rows mount here; cleared on every navigation -->
  <div id="header-extras"></div>

</div>

A page adds rows from inside its render(): 

document.getElementById("header-extras").innerHTML = `
  <div class="px-3 pb-3 text-sm text-fg-muted">Detail row…</div>
`;
