Chip & badge

Inline status badge for short labels — <rurio-badge>. Adapted from the Tailwind Plus badge set (pill variants only — the “flat” variants are intentionally excluded) and mapped onto our six semantic intents (neutral, accent, success, warning, danger, info). Built entirely from Tailwind utility classes; base font size is text-base (16px).

Pill

Fully-rounded badge (shape="pill") with a subtle intent fill.

Selectable (filter toggle)

Add selectable to turn the badge into an on/off toggle (used by the parcels filter chips). It's keyboard-operable and fires rurio:badge-toggle with { value, selected }. Add color="…" for a per-item custom color (e.g. crop colors) — the selected state fills with that color and the leading dot uses it.
