Component

Button group

Segmented control for picking exactly one option from 2–5 mutually exclusive choices. Pattern from Tailwind Plus, themed with design–system tokens. Outer border-radius matches --radius-lg; rings live on each item so the active one renders cleanly above its neighbors.

In context

Used as the controls inside the user profile page (theme, mode, font size).

Default

Three options

Click an item to toggle

With icons

Two options
