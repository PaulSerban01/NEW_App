Component

Summary bar

Fixed sub-header — <rurio-summary-bar> — used on the parcels list & map. Holds a season / date-range picker on the left (predefined seasons plus a custom “De la / Până la” range) and an optional view switcher on the right. Configured via the .config property.

Interactive demo

Open the picker, choose a season or set a custom range, and switch views. Add the static attribute (used here) to drop the fixed positioning when embedding.

Conținutul paginii…

Selectează un interval.

Type sizing & scaling

All text uses rem-based Tailwind classes, so the bar responds to the Mărime text preference (--font-scale). Defaults:

ElementClassDefault (Medium)
Trigger labeltext-base16px
Season presetstext-base16px
Date inputstext-base16px
“Aplică” buttontext-base16px
Section labels (Predefinite / De la / Până la)text-xs12px

The small labels were previously a fixed text-[11px] that ignored the size preference — now text-xs, so they scale with everything else.

Anatomy

<rurio-summary-bar id="bar"></rurio-summary-bar>

<script type="module">
  import "../../components/index.js";
  const bar = document.getElementById("bar");
  bar.config = {
    dateRange: {
      start: "2025-09-01",
      end:   "2026-08-31",
      ariaLabel: "Interval",
      presets: [
        { id: "2025-2026", label: "Sezon 2025-2026", start: "2025-09-01", end: "2026-08-31" },
        { id: "apia-2025-2026", label: "Apia 2025-2026", start: "2025-10-01", end: "2026-09-30" },
      ],
    },
    views: [
      { id: "list", icon: "list",  href: "#/parcels", label: "Listă" },
      { id: "map",  icon: "globe", href: "#/map",     label: "Hartă" },
    ],
    activeView: "list",
  };
</script>

Events & attributes

APIDescription
.configObject — dateRange (start/end/presets/ariaLabel), views, activeView.
static attrDrops the fixed positioning + spacer (for mounting inside an already-fixed container).
rurio:summary-changeBubbling event with { start, end } when the range changes.
rurio:route-changeListened on document → auto-syncs activeView.
