Target is WCAG 2.2 AA. Every semantic pairing below was tuned to clear 4.5:1 for body text, 3:1 for large text and UI.

Touch targets

44 × 44 minimum
All interactive components default to min-height: 44px. Small (--sm) variants drop to 36px only when stacked in a form row where the whole row is tappable.

Focus

A 3px accent-tinted ring appears on keyboard-only focus. Never remove it — override with var(--shadow-focus) if a custom component needs its own.

In React Native

  • Use accessibilityRole on every pressable.
  • Provide accessibilityLabel for icon-only buttons.
  • Set accessibilityState for toggles, selected chips, and disabled inputs.
  • Respect useReducedMotion — swap scale animations for fades.
