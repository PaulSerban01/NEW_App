Usage rules

  • Mobile body default is 15px. Use 16px (body-lg) for settings screens and long-form reading.
  • Never go below 11px on-screen. Hint text at 12px must pair with at least medium weight if it sits on a tinted background.
  • Reach for H roles via semantic tokens (--h1-size, --h1-weight) — don't read primitives directly.
  • Numerals in the stat card use tabular-nums (font-variant-numeric: tabular-nums).
