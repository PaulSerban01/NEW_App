Rurio · v0.1

A design system for managing farms, calmly.

Rurio is the design system for a React Native app that helps farm operators run their business — companies, people, assets and the news that matters to them. Built on three-tier tokens, three palettes with light + dark, Inter type, and WCAG 2.2 AA contrast throughout.

Start here

The system is organised the way you'll use it. Foundations first — the atoms every component is built from. Then components, drawn inside real iOS and Android device frames so you can see them in context.

Foundation

Token architecture

Three-tier tokens — primitive, semantic, component — compatible with Figma Variables modes.
Foundation

Colors

Three palettes × light + dark. Every text pairing meets AA. Ramps span 0 → 950 with prefixes.
Foundation

Typography

Inter, tuned for dense mobile UI. Semantic roles: display, h1–h5, body, label, caption, overline.
Component

Button

Primary, secondary, ghost, destructive and icon. Three sizes, all states, 44px min target.
Component

Input

Text, search, password, textarea. Leading/trailing slots, error and disabled states.
Component

Card

Flat, outlined, elevated, filled. Media, header, body, footer — ready for farm summaries.

What makes it work

Architecture

Semantic tokens, not primitives

Components reference --accent-bg, never --teal-700. Swap a palette — the whole UI re-themes.

Accessibility

AA verified at source

Text tokens are tuned so body copy hits 4.5:1 and UI elements hit 3:1 in every theme × mode combination.

Translation

Figma-compatible modes

Palette and mode are modes on html, mirroring the Figma Variables model exactly.

Try the switcher

In the top right, switch palettes and toggle dark mode. Watch every card, button and tint rebind — nothing hardcoded. This is how the app will feel on a user's device when they pick a theme.
